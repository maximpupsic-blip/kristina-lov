РОМАНТИЧЕСКИЙ САЙТ ДЛЯ КРИСТИНЫ

1. Распакуй папку на компьютер.
2. Открой Visual Studio Code.
3. Нажми File → Open Folder и выбери папку romantic_site_kristina.
4. Открой index.html. Для просмотра можно установить расширение Live Server, нажать правой кнопкой по index.html и выбрать Open with Live Server.
5. Фото положи в папку photos под именами photo1.jpg, photo2.jpg, photo3.jpg.
6. Отредактируй текст в index.html, если хочешь добавить ваши личные воспоминания.

БЕСПЛАТНАЯ ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES
1. Создай аккаунт на https://github.com/.
2. Создай новый публичный репозиторий, например kristina-love.
3. Загрузи index.html и папку photos в корень репозитория (не сам ZIP).
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch, branch main, folder /(root), затем Save.
6. Подожди несколько минут — GitHub покажет адрес сайта в Settings → Pages. Отправь эту ссылку Кристине.

Совет: репозиторий Public означает, что загруженные файлы сайта доступны публично. Не добавляй адреса, пароли или другие личные данные.
